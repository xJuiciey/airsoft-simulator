# PEI world data bundle

This directory contains geographic source data used by the PEI open-world map.

- **Building footprints:** Microsoft Canadian Building Footprints, Prince Edward Island extract. Source polygons are computer-generated from aerial imagery and are used as building ground plans. Licensed under the Open Database License (ODbL). The in-game building height, roof, windows and doors are procedural approximations, not surveyed facade scans.
- **Roads, waterways and mapped forest polygons:** OpenStreetMap contributors, queried for the Sturgeon district and cached during the GitHub Actions data-build workflow. © OpenStreetMap contributors, ODbL.

The current cached bundle covers the Sturgeon map bounds only. It is not yet the full-island streaming dataset.
